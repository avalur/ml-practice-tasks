Quality Levers: Quick Wins

1. Tool Descriptions
+ Structured Output
WHY: LLM picks tool by its description. Vague desc → wrong tool called.
HOW: JSON schema forces valid output structure (no free text, no hallucination in field names)
2. Few-Shot
Examples
WHY: LLM learns from examples, not rules. 'Clarify dates' in prompt → ignored. Same as example → followed.
HOW: 3-5 input/output pairs in system prompt. +10-15% quality
3. Chain-of-Thought
WHY: complex queries need step-by-step. 'Find cheapest connecting flight' needs reasoning.
HOW: 'Think step by step' or structured reasoning. +10-20% quality

Quality Levers: Heavy Artillery

4. DSPy (sweet spot)
Algorithm finds best prompt
Auto-generates few-shot
Rewrites instructions
Needs: 20 test cases + metric
Result: +20-30% quality
5. Fine-tuning (last resort)
Train the model itself
Maximum quality + speed
Needs: 1000+ labeled examples
Cost: GPU time + maintenance
Only if 1-4 aren't enough
DSPy automates what you'd do manually: pick examples, rewrite instructions.
Fine-tuning changes the model — expensive, rarely needed. Go top-down.
